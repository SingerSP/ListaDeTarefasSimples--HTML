## 🚀 Funcionalidades

### 🎯 Principais
- ✅ **Adicionar tarefas** - Insira novas tarefas rapidamente
- 📋 **Listar tarefas** - Visualize todas as suas tarefas organizadas
- ✏️ **Editar tarefas** - Modifique tarefas existentes com um clique
- 🗑️ **Excluir tarefas** - Remova tarefas individualmente
- ✔️ **Marcar como concluída** - Controle seu progresso

### 🔧 Avançadas
- 🎛️ **Sistema de filtros** - Visualize todas, pendentes ou concluídas
- 📊 **Estatísticas em tempo real** - Acompanhe seu progresso
- 💾 **Persistência de dados** - Suas tarefas são salvas automaticamente
- 🧹 **Limpar concluídas** - Remova todas as tarefas finalizadas de uma vez
- 📱 **Design responsivo** - Funciona perfeitamente em todos os dispositivos
